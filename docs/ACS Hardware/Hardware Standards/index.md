# Overview

This section of the documentation covers the technical standards for hardware intended to be part of the Access Control Deployment. 

This documentation represents the current proposed **3.0.0** hardware standard. 

## Summary

The SHED ACS (Access Control System) defines a series of standards to ensure interoperability of different electrical devices, running different code, within a single deployment. 

This specification covers electrical standards, communication standards, connector standards, and defines a system topology.

## Glossary

**Core** : The Core is the master component of an ACS deployment. Without specific circuitry, only one Core can exist in a deployment.

**Switch** : The component of an ACS deployment that handles restricting access to equipment.

**Deployment** : All interconnected components used for ACS.

**Branch** : A series of interconnected ACS devices in a deployment, with either a line terminator or switch on both ends.
