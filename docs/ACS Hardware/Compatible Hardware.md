# Compatible Hardware

Below are some projects that work with ACS, but are not necessarily part of Access Control. These are to show examples of the versatility of ACS in larger systems.

For more information on creating compatible hardware, see [Hardware Standards](../Standards/index.md).

## Automated Blast Gates 

The SHED Makerspace developed a custom blast gate control system that uses the ACS signal for determining when to open the blast gates.

This system is still under development, please check back later.

## Laser Monitor

The Laser Monitor is an accessory that sits between an Epilog laser cutter and its accompanying BOFA fume extractor. In addition to flashing a warning / sounding an alarm in the event of a fume extractor or air compressor fault, the system can integrate with access control to make the equipment unavailable in the event of a fault. 

For more information, visit [the GitHub repository](https://github.com/rit-construct-makerspace/laser-monitor){target="_blank"}
